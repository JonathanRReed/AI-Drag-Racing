## 2025-05-20 - 60Hz Pace Chart GC Pressure & SSE Array Pipelines
**Learning:** In 60Hz requestAnimationFrame SVG charts (like `LivePaceChart`), calling `decimate()` creates ~600 array allocations/sec across multiple lanes, and calling `.toFixed(1)` per point creates ~200k string objects/sec, causing main-thread stutters during live races. Passing a reusable array buffer to `decimate()` and using `Math.round(val * 10) / 10` eliminates per-frame heap allocations. Additionally, array chaining (`split.filter.map`) in SSE stream parsers creates thousands of unnecessary intermediate objects per second during high-speed streaming.
**Action:** When working on rAF canvas/SVG renderers, pass reusable output buffers to array-transforming helpers and use numeric rounding instead of `.toFixed()`. In streaming handlers, replace array pipelines with single-pass loops.
